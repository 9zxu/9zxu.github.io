```bash
winget install Hugo.Hugo.Extended
```

## new site
```bash
hugo new site [site-name]
```
This will create a folder named `[site-name]`
## apply theme
search theme from [hugo theme](https://themes.gohugo.io/)

### install [paper](https://github.com/nanxiaobei/hugo-paper.git) theme as git submodule
Inside the folder of your Hugo project, run:
```bash
git submodule add https://github.com/nanxiaobei/hugo-paper themes/paper
```
Open `hugo.toml`, change theme to `"paper"`:
```toml
theme = "paper"
```
## add content
```bash
hugo new posts/<file-name>.md
```
> Note that if the article is not located under `[site-name]/content/posts`, it will not be able to be shown.

## Host on GitHub Pages
> [official guide](https://gohugo.io/host-and-deploy/host-on-github-pages/)

The site will be built and deployed by GitHub Action.

under `[site-name]`
```bash
git remote add origin https://github.com/[user-name]/[user-name].github.io.git
git config --global user.name [name]
git config --global user.mail [mail-address]
```
```bash
git add .
git commit -m "[commit-message]"
git push
```
Navigate to your repo > acrtion page, once deployed successfully, you can access the website.
